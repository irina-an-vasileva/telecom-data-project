# telecom-data-project
Сбор, обработка и визуализация данных об операторах связи в РФ.  В проекте используются Selenium для парсинга данных с сайта Роскомнадзора, Pandas для обработки данных,Tableau — для визуализации.

## Технологии
- Python
- Selenium
- Pandas
- Tableau

## Структура проекта
- `Парсер_операторы_Связи.ipynb` — ноутбук для парсинга данных с сайта Роскомнадзора.
- `Визуализация_операторы_Связи.ipynb` — ноутбук для визуализации данных.
- `df_company.csv` — данные о компаниях (названия, ИНН, ОГРН).
- `df_license.csv` — данные о лицензиях операторов связи.
- `df_license_region.csv` — данные о регионах действия лицензи.
